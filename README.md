# Historias Vivas

Motor narrativo persistente para crear y vivir historias interactivas que evolucionan con las decisiones del usuario.

## Engine 0.1

Objetivo inicial: demostrar continuidad narrativa real entre sesiones mediante un mundo persistente, personajes autónomos, memoria, acontecimientos y consecuencias.

### Principios

- Mundo persistente y coherente.
- Memoria narrativa a corto, medio y largo plazo.
- Personajes con objetivos, relaciones y conocimiento propio.
- Consecuencias inmediatas y diferidas.
- Director narrativo separado del proveedor de IA.
- Entrada libre del usuario.
- Intensidad narrativa configurable y prosa elegante.
- Posibilidad real de fracaso y finales orgánicos.
- Arquitectura preparada para integrarse posteriormente en MiBiblioteca.

## Estado

🚧 En desarrollo — Engine 0.1.
